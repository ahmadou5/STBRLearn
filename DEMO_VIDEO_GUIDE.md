# 🎬 Demo Video Guide

Complete guide for creating your 3-5 minute demo video for Superteam Academy.

---

## 🎯 Video Requirements

- **Duration**: 3-5 minutes (aim for 4 minutes)
- **Format**: Screen recording with voiceover or captions
- **Quality**: 1080p (1920x1080) minimum
- **Platform**: YouTube, Loom, or Vimeo
- **Language**: English (preferred) or Portuguese

---

## 📝 Video Script Template

### Introduction (30 seconds)

**What to say:**
> "Hi! I'm [Your Name], and I built Superteam Academy - a gamified learning platform for Solana developers. Let me show you how it works."

**What to show:**
- Landing page hero section
- Briefly scroll through features
- Show the Superteam branding

### Section 1: Course Catalog (45 seconds)

**What to say:**
> "The platform offers three learning paths: Solana Development, DeFi, and NFTs. Each course is designed for different skill levels, from beginner to advanced."

**What to show:**
- Navigate to `/courses`
- Show the course grid
- Highlight difficulty badges (beginner, intermediate, advanced)
- Show course cards with XP rewards
- Click on "Solana Fundamentals" course

### Section 2: Course Detail (30 seconds)

**What to say:**
> "Each course is broken down into modules and lessons. You can see your progress, total XP available, and the course structure."

**What to show:**
- Course detail page with modules
- Scroll through Module 1 and 2
- Show lesson types (theory lessons vs coding challenges)
- Show the "Start Course" button

### Section 3: Wallet Connection (30 seconds)

**What to say:**
> "To track your progress on-chain, connect your Solana wallet. The platform supports Phantom, Solflare, and other popular wallets."

**What to show:**
- Click wallet button in header
- Show wallet selection modal
- Connect Phantom or Solflare
- Show connected wallet address in header

### Section 4: Interactive Lesson (60 seconds)

**What to say:**
> "Lessons include both educational content and hands-on coding challenges. The platform integrates Solana Playground for an interactive coding experience."

**What to show:**
- Click on a lesson (e.g., "Introduction to Solana Programs")
- Show the lesson content on the left
- Show the embedded Solana Playground on the right
- Scroll through the lesson content
- Click "Mark Complete" button
- Show XP earned notification (if implemented)

### Section 5: Dashboard (45 seconds)

**What to say:**
> "The dashboard shows your learning progress with XP tracking, level progression, achievements, and daily streaks to keep you motivated."

**What to show:**
- Navigate to `/dashboard`
- Show XP balance and current level
- Highlight the progress bar to next level
- Show achievement badges (earned and locked)
- Show the streak calendar
- Point out "Continue Learning" section

### Section 6: Leaderboard (30 seconds)

**What to say:**
> "Compete with other learners on the global leaderboard. Top performers get special recognition with podium positions."

**What to show:**
- Navigate to `/leaderboard`
- Show the podium (top 3)
- Scroll through the leaderboard table
- Show XP amounts and levels

### Section 7: Profile & Settings (20 seconds)

**What to say:**
> "Your profile showcases your credentials, achievements, and learning stats. Settings allow you to customize your experience."

**What to show:**
- Navigate to `/profile`
- Show credentials and stats
- Navigate to `/settings`
- Briefly scroll through settings options

### Conclusion (20 seconds)

**What to say:**
> "Superteam Academy is built with Next.js, Solana Web3.js, and designed for easy content updates. The architecture supports future on-chain integration for verifiable credentials. Check out the live demo and GitHub repo - thanks for watching!"

**What to show:**
- Return to landing page
- Show footer with GitHub link
- End screen with URLs

## 🛠️ Recording Tools

### Option 1: Loom (Easiest - Recommended)

**Pros:** Free, easy to use, automatic upload, shareable link
**Cons:** 5-minute limit on free plan (perfect for this use case)

**Steps:**
1. Sign up at [loom.com](https://loom.com)
2. Download Loom desktop app or Chrome extension
3. Click "Record" → "Screen Only" or "Screen + Camera"
4. Select your browser window
5. Click "Start Recording"
6. Follow the script above
7. Click "Finish" when done
8. Get shareable link instantly

### Option 2: OBS Studio (Advanced)

**Pros:** Free, full control, no time limits, best quality
**Cons:** Steeper learning curve

**Steps:**
1. Download [OBS Studio](https://obsproject.com)
2. Create a scene with "Display Capture" or "Window Capture"
3. Set resolution to 1920x1080
4. Click "Start Recording"
5. Follow the script
6. Click "Stop Recording"
7. Upload to YouTube

**OBS Settings:**
- Resolution: 1920x1080
- FPS: 30 or 60
- Format: MP4
- Encoder: H.264

### Option 3: macOS QuickTime (Mac Only)

**Pros:** Built-in, simple, good quality
**Cons:** Mac only, need separate upload

**Steps:**
1. Open QuickTime Player
2. File → New Screen Recording
3. Select recording area (full screen recommended)
4. Click record button
5. Follow the script
6. Click stop in menu bar
7. File → Export As → 1080p
8. Upload to YouTube

### Option 4: Windows Game Bar (Windows Only)

**Pros:** Built-in to Windows 10/11
**Cons:** Limited features

**Steps:**
1. Press `Win + G` to open Game Bar
2. Click the record button (or `Win + Alt + R`)
3. Follow the script
4. Press `Win + Alt + R` to stop
5. Find video in `Videos/Captures` folder
6. Upload to YouTube

## 🎤 Audio Tips

### For Voiceover:

1. **Find a quiet space** - No background noise
2. **Use a decent microphone** - Built-in laptop mic is okay, external is better
3. **Speak clearly** - Not too fast, not too slow
4. **Be enthusiastic** - Show excitement about the project
5. **Practice first** - Do a test recording

### For Silent Video with Captions:

If you prefer not to do voiceover:

1. Record the video silently
2. Add text overlays using:
   - **YouTube Studio** (free, after upload)
   - **Kapwing** ([kapwing.com](https://kapwing.com))
   - **Adobe Premiere** (if you have it)
3. Add background music (optional):
   - [YouTube Audio Library](https://www.youtube.com/audiolibrary)
   - Keep volume low (10-20%)

## ✅ Pre-Recording Checklist

Before you start recording:

- [ ] Clear browser cache and restart browser
- [ ] Close unnecessary tabs and applications
- [ ] Set browser to 1920x1080 window size (or full screen)
- [ ] Zoom level at 100% in browser
- [ ] Dark theme enabled (looks better on video)
- [ ] Wallet ready to connect (Phantom or Solflare)
- [ ] Practice the script once
- [ ] Check microphone levels
- [ ] Disable notifications (Do Not Disturb mode)
- [ ] Hide bookmarks bar (cleaner look)
- [ ] Have the script visible on another screen or printed

---

## 🎨 Visual Polish Tips

1. **Cursor Highlighting**: Enable cursor highlighting in recording software
2. **Smooth Scrolling**: Scroll slowly and smoothly
3. **Pauses**: Brief pause (1-2 sec) when transitioning between pages
4. **Full Page Loads**: Let pages fully load before interacting
5. **Clean Desktop**: Hide desktop icons if doing full screen capture

---

## 🚫 Common Mistakes to Avoid

❌ **Don't:**
- Rush through the demo
- Show errors or bugs
- Include personal information (email, wallet private keys)
- Have messy browser tabs visible
- Forget to show key features (dashboard, leaderboard)
- Go over 5 minutes

✅ **Do:**
- Speak clearly and confidently
- Highlight unique features (gamification, embedded editor)
- Show actual interaction (wallet connect, navigate pages)
- Keep it concise and engaging
- End with a clear call-to-action
