## ⏱️ Time Remaining: ~90 minutes

### Step 1: Deploy to Vercel (15 minutes) 🚢

**What to do:**
1. Push your code to GitHub (if not already done)
2. Go to [vercel.com](https://vercel.com) and sign in
3. Click "Add New" → "Project"
4. Import your GitHub repository
5. Add environment variables:
   ```
   NEXT_PUBLIC_SOLANA_NETWORK=devnet
   NEXT_PUBLIC_SOLANA_RPC_HOST=https://api.devnet.solana.com
   NEXT_PUBLIC_APP_URL=https://your-app.vercel.app
   NEXT_PUBLIC_APP_NAME=Superteam Academy
   ```
6. Click "Deploy" and wait 2-3 minutes
7. **Copy your production URL** (e.g., `https://your-app.vercel.app`)

**📖 Full Guide:** See [DEPLOYMENT.md](./DEPLOYMENT.md)

### Step 2: Record Demo Video (45 minutes) 🎬

**What to do:**
1. Go to [loom.com](https://loom.com) and sign up (free)
2. Download the Loom app or Chrome extension
3. Click "Start Recording" → "Screen Only"
4. Follow the **4-minute script** from DEMO_VIDEO_GUIDE.md:

5. Click "Finish" and get your shareable link

### Step 4: Submit Pull Request (15 minutes) 📤

**What to do:**

1. **Fork** the repository:
   - Go to https://github.com/solanabr/superteam-academy
   - Click "Fork" button

2. **Clone your fork:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/superteam-academy.git
   cd superteam-academy
   ```

3. **Create feature branch:**
   ```bash
   git checkout -b feat/your-implementation
   ```

4. **Add your changes:**
   ```bash
   # Copy all your files to this directory
   git add .
   git commit -m "feat: Add interactive Solana learning platform"
   ```

5. **Push to your fork:**
   ```bash
   git push origin feat/your-implementation
   ```

6. **Create PR on GitHub:**
   - Go to your fork on GitHub
   - Click "Pull Request" button
   - Use the template from [PR_SUBMISSION_TEMPLATE.md](./PR_SUBMISSION_TEMPLATE.md)
   - Include your demo URL and video link
   - Click "Create Pull Request"

**📖 Full Guide:** See [PR_SUBMISSION_TEMPLATE.md](./PR_SUBMISSION_TEMPLATE.md)
